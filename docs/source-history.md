本项目先在独立本地 Git 仓库实现并验证，随后接入用户提供的空 GitHub 仓库。命令行 Git 具备公开读取能力，但没有写入登录凭据；GitHub 连接器具有该仓库写权限，因此通过其 Git 数据接口导入。

导入按本地提交的原始顺序进行。每个阶段用已提交文件的准确字节、模式和路径重建树，并要求 GitHub 返回的树 SHA 与本地同一提交的树 SHA 完全相同。新提交说明保留原消息，并附加 `Source-Commit` 与原始记录时间。

连接器会生成新的提交身份和时间，因此 GitHub commit SHA 与本地 SHA 不同；这不改变文件树。最终只在整条历史导入、树一致性核对和当前分支前置值校验成功后，一次性更新 main。不会强制覆盖新出现的远端提交。
