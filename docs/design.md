# 模块化文字世界：可执行基础 v0.3

本项目独立于词条组合游戏。所有现有和未来系统、规则、内容、数据、表现与操作都默认模块化。以下实现样例只检验架构，不是未来功能白名单。

## 本轮目标

建立会继续使用的 TypeScript 工程：模块注册与能力装配、单宿主事务、命令与事件、可替换规则、保存恢复与显式迁移、独立文字输出适配器、命令行操作、三类世界样例及自动验证。

底层不知道角色、生命、背包、时间、农场或战棋。它只认识版本化契约、模块实例、JSON 状态和消息。能力按实例绑定，多个提供者冲突时必须指定；官方模块与外部可信模块使用同一入口。现在只加载可信本地代码，尚无不可信脚本隔离。

## 技术取舍

沿用已提出的 TypeScript 独立核心方向。使用 Node.js 24.12+ 原生类型擦除执行开发源码，TypeScript 5.9.3 做严格类型检查和 JS 构建；Ajv 8.17.1 验证 JSON Schema，semver 7.8.5 校验依赖范围。Node 的类型擦除不是类型检查。未来浏览器适配不应改变核心规则。

原 Evennia、boardgame.io、Colyseus 等候选已有研究记录；它们各自的世界、时间或对局假设不能替代本项目的模块契约。核心适配层自建；数据校验和版本范围复用成熟库。外部游戏规则本轮依据已读语义设计独立职责，不导入整套引擎。具体源码移植仍需逐模块来源与许可记录。

## 执行语义

命令同步执行，模块只能写自身状态。嵌套能力调用共用事务；事件按队列和装配次序处理，任一规则失败则状态、事件序号、版本与幂等记录均回滚。设事件与调用预算防止无限递归；这是错误保护，不是恶意代码沙箱。查询取得独立数据副本，不提供写入入口。

世界可完全不含时间或库存。时间、随机来源同样是模块。作物读取显式模拟秒，阶段时钟与连续时钟仅改变推进命令；一回合到模拟秒的映射由配置提供。事件订阅必须核对 source 为已绑定提供者，不能被另一时间域误推进。

存档包含世界装配、模块准确版本、状态格式、事件游标、逻辑版本及有限幂等回执。缺模块、坏数据和不兼容版本明确拒绝。切换模块在副本上重装；更换代码身份/版本/状态格式需要迁移。丢弃已有模块要求调用者显式列出。失败不修改旧实例。原子提交只覆盖同一宿主，尚无跨服转移协议。

## 验证样例

1. 经营链：种子出库、播种、推进、收获、出售；格子/重量/容积约束可换，规则可组合，土壤倍率可作为独立模块接入。
2. 回合战棋：空间、移动、交战和回合的模块级运行，不要求库存或经营。命中使用独立随机能力，可存档恢复。
3. 叙事世界：仅可选择的节点与文字视图，不加载时间、库存、战斗。证明这些系统不是宿主必选组件。

CLI 是架构验证与作者工具，不是已批准的正式游戏 UI。正式视觉界面按现有协作规范在图片样板确认后实现。本轮不会把命令行的表现当最终视觉方向。

## 失败与长期路径

检查：坏 JSON、重复实例 ID、缺依赖、版本不兼容、能力歧义、循环调用、事件风暴、数值越界、负数量、库存不足、目标容量不足、未成熟收获、重复命令、重复命令 ID 不同内容、损坏/旧版存档、迁移失败、删除状态模块。模块示例数值只服务验证，尚未平衡与真实游玩评价。
