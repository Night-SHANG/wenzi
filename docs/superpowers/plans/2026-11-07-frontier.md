# Frontier Exploration and Production Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a repeatable modular explore/gather/craft/trade/save loop and two composable world configurations.

**Architecture:** New location, gathering policy/state, recipe catalog and single-job crafting modules consume existing public capability interfaces. A separate text view and data-only worlds compose them with existing inventory, time and market modules; the engine and CLI stay generic.

**Tech Stack:** Node.js >=24.12.0, TypeScript 5.9.3, existing Ajv 8.17.1 / semver 7.8.5 / fast-json-patch 3.1.1; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-07-frontier-design.md`

## Global Constraints

- 全部现有和未来系统、规则、数据、内容、表现、界面与操作均模块化，具体样例不限定范围。
- 不修改 `src/engine`、`src/contracts.ts` 或为新世界增加 CLI 分支；通过公开 `ModuleDefinition` 与能力绑定接入。
- Node.js >=24.12.0，TypeScript 5.9.3；沿用 Ajv 8.17.1、semver 7.8.5、fast-json-patch 3.1.1，本轮不加依赖。
- 所有新增定义 version=1.0.0、apiVersion=1、stateVersion=1；声明的能力版本为 1.0.0，依赖范围为 ^1.0.0。
- 各模块只写自己的状态；库存增减、冷却和生产状态必须在已有宿主事务中原子提交。
- 时间只消费绑定提供者的 `time.now -> {elapsedSeconds}`，单位为模拟秒；不猜测 `advance` 的参数，不订阅无关时钟。
- 数量为正安全整数，时间为有限安全非负数；正时长相加后必须严格增加，溢出或精度丢失拒绝。复用 capacity.ts 的 schema、own、safeNumber、safeCount。
- 读取外部能力返回值时检查必要字段与数值，不把 TypeScript 断言当运行时校验。所有 ID 按自有属性查找，安全支持合法的原型同名键。
- 既有世界和存档格式保持可用；同版本配置更换保留状态，无法对应的已有状态明确拒绝。新模块不承诺自动跨代码版本迁移。
- 正式视觉界面仍先经过视觉样板确认；本轮扩展现有纯文字作者界面，不设新的视觉审批点。

## Review Focus

- Multi-output receipt/refund capacity failure must roll back earlier inventory writes and leave the job unchanged (Task 2).
- Changing/removing recipes after payment must not reinterpret a job; removing referenced saved-state resources must reject replacement without changing the old world (Tasks 1, 2).
- Wrong clock/provider binding, backward time, huge finite values and sub-precision positive durations must fail without mutation (Tasks 1, 2).
- Prototype-like authored IDs and malformed external capability return values must not access inherited properties or evade numeric checks (Tasks 1, 2).
- Built JS, real file save/restore, author fork/patch, and clock swaps must work for the new world without a dedicated CLI path (Task 3).
