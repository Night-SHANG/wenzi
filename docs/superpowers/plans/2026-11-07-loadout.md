Read AGENTS.md and the complete design before implementation. All module IDs, exports, inputs/outputs and ownership in the design are binding. Root alone stages/commits and edits registry/worlds/shared docs. Workers do not spawn agents or run global suites/builds; use focused node --test commands and write genuine RED/GREEN evidence. Root runs full suite through Preflight once owners/review fixes are stable. No duplicate inventory, XP, health, battle or clock authority. IDs are Unicode code points; queries pure; failed nested operations atomically roll back. Clock units are cumulative simulation seconds, not wall time. Preserve independently replaceable rules and explicit version migrations.
