# 独立世界规则交付记录

## 实现范围

- `src/modules/adventure.ts` 导出五个公开 `ModuleDefinition` 的 `adventureModules`。
- `random.seeded` 提供 `random@1.0.0`，仅自身状态存储随机流；按 xorshift32 的 13/17/5 位移推进，返回 unsigned uint32 / 2^32。安全整数 seed 先按 uint32 归一，结果为零时改用 `0x6d2b79f5`。
- `tactics.grid` 仅要求 `random` 能力。移动按曼哈顿距离扣除 `remainingMove`，攻击独立消耗 `acted`；每次切换阵营回合数加一并重置进入阵营。敌方通过同一命令接口操作，无自动 AI。
- `narrative.branching` 自含图配置与 `{node,visits}` 状态；初始节点计第一次访问。图校验覆盖起点、引用与单节点重复选项 ID。
- 两个文字视图通过能力查询规则模块，均无 DOM、时间或库存依赖。

全部为本项目独立代码；格战仅为证明不同规则族可运行的最小样例，并非 Wesnoth 精确实现，也未复制其源码。世界 JSON 与 CLI 由主任务管理。

## 测试与验证

先创建 `tests/adventure.test.ts`，再创建实际模块文件。首次运行 `node --test tests/adventure.test.ts` 因并行宿主尚未生成 `src/engine/index.ts` 而失败；这次运行只证明依赖缺失，没有实际运行行为断言。

已编写以下真实宿主集成测试：

1. 仅叙事与视图组成世界；非法选项不改变整个快照；合法选择发事件并增加访问数。
2. 非法图起点、悬空引用及重复选项 ID 拒绝装配。
3. 错误阵营、范围、越界、占位移动及重复攻击失败，快照与随机流不变；攻击后仍能移动。
4. 完整双方操作推进战斗、回合重置、死亡状态保留、视图输出及终局行动拒绝。
5. seed=1 第一项数值、seed=0 替代值与保存恢复后的后续五次随机流一致。
6. 外部命令先调用随机源再失败，随机源写入也回滚。
7. 重命名全部模块身份后仍可经公开宿主运行叙事。
8. 命中率为零的攻击仍消耗一次攻击资格及随机抽取。
9. 第三方随机源返回非法值时产生明确规则错误且嵌套写入回滚。

宿主生成后的第一次完整目标运行：9 项中 8 项通过，非法随机提供者测试失败，实际错误码为 `MODULE_ERROR` 而非期望的 `TACTICS_RANDOM`。模块增加返回值形状检查后，目标测试 9/9 通过。其后严格类型检查暴露动态 JSON 值的缩窄问题，已用显式 `return context.fail(...)` 修正。

最终实际执行结果：

- `node --test tests/adventure.test.ts`：9 项通过，0 项失败。
- `npm run typecheck`：退出 0，无 TypeScript 错误。
- `npm test`：全工程 44 项通过，0 项失败；包含冒险、宿主、经营链、CLI 与存储测试。

前期全项目类型检查曾被并行 farm/market 的类型错误阻塞，最终运行已不再出现。npm 仅输出环境中的 `Unknown env config "http-proxy"` 提示，不影响本轮退出状态。没有遗留失败或尚缺依赖。

## 语义与边界

格战坐标宽高是 1–1000，位置从零开始；初始 HP 必须正整数，伤害及移动力允许为零，命中率为 [0,1]。目标格必须为空，未实现路径障碍、寻路、地形、反击或 AI。死亡单位保留记录且不占据目标格。固定单位属性及 HP 上限与配置一致性由校验钩子检查。

未做图形 UI、移动设备验证、游戏数值平衡、性能压力或不可信代码沙箱测试；这些不属于本次规则证明范围。初次依赖缺失属于真实限制，不声称该次运行已完成行为测试。
