# Task 1 — Public module host

Read src/contracts.ts and docs/design.md. Own ONLY src/engine/** and tests/engine.test.ts. No other edits/commits; root manages shared dependencies and integration. Do not spawn agents.

Export from src/engine/index.ts: ModuleRegistry, WorldRuntime, createWorld(registry, definition), restoreWorld(registry, snapshot), reconfigureWorld(registry, oldWorld, nextDefinition, options?). ModuleRegistry constructor accepts ModuleDefinition[] and register(definition): void. WorldRuntime methods: dispatch(command): CommandResult; query(instanceId, action, input={}): JsonValue; snapshot(): WorldSnapshot; read(instanceId): JsonValue; actions(): {target:string; action:string; schema:JsonSchema}[]; definition getter returns defensive copy; revision getter number.

Registry validates manifest, duplicate IDs and schemas using Ajv; use semver for version ranges. Resolve required capabilities to explicit bindings or the only compatible provider; reject missing, incompatible and ambiguous providers, duplicate instances, unknown bindings and declared conflicts. Bindings are per instance, not global. Do not reject a capability cycle merely for being a graph cycle; cap actual nested calls/queries at 64.

Use src/contracts.ts exact names. Each transaction starts with detached JSON state; nested calls share it. Execute all queued events deterministically, cap at 1024 events. Copy/freeze read inputs so query/state mutation cannot alter authoritative state. Query contexts have no write/call/emit. Validate input/config/state via Ajv and reject non-JSON/nonfinite values; module validate hooks run on initial/restore/commit. Exceptions become CommandFailure with code and message; all state, revision, events, receipts roll back on failure. Config/state serializers must not allow prototype pollution or undefined JSON loss. Read-only malicious query mutation should be harmless; trusted code boundary remains explicit.

Successful nonempty command.id stores a bounded last-128 receipt with canonical input fingerprint; replay returns same result with replayed=true and no second mutation. Same ID/different command fails with DUPLICATE_COMMAND. Failed commands are not cached. No-ID command always executes. Preserve receipts in snapshots. Return copies of results and snapshots.

restoreWorld verifies format, definition, per-instance module identity/version/stateVersion and all states; unknown/missing or extra saved modules fail. If code identity/version/stateVersion differs, require module.migrate then validate; never silently reset. reconfigureWorld requires same world ID, retains states for retained instances, requires migrate on changed code identity/version/stateVersion, and rejects removing old instances unless allowRemoved explicitly lists each removed ID. Add new modules via initialState; all reconfiguration works on copies and preserves original on failure. Clear dedup receipts on successful reconfigure. Pure schema/validate hooks check migrated states. Initial state/config consistency included.

Use node:test + assert to test behaviour before implementation. Minimum: dependency resolution failure and ambiguity; non-whitelisted module; nested atomic failure; query mutation isolation; dedup mismatch/replay; event error rollback and storm bound; snapshot restore; missing module/corrupt snapshot; failed migration unchanged; explicit allowed removal; unsafe JSON rejects. Deterministic errors should have stable codes, Chinese messages welcome. Report exact tests run and unresolved limits to docs/tasks/host-report.md (owned report allowed). Dependencies installed by root; use npm test -- --test-name-pattern only if correct Node syntax, otherwise node --test tests/engine.test.ts.
